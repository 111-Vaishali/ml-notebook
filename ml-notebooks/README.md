# 🤖 ML Notebooks — Vaishali G. Sunepwar

A collection of machine learning experiments, EDA, and mini-projects built as part of my B.Tech CSE (AIML) journey at PCCOE Pune.

## 📁 Structure

| Folder | Notebook | Description |
|--------|----------|-------------|
| `01_EDA` | `titanic_eda.ipynb` | Full EDA on Titanic dataset |
| `01_EDA` | `iris_eda.ipynb` | EDA on Iris classification dataset |
| `02_Supervised_Learning` | `linear_regression_house_price.ipynb` | Predicting house prices |
| `02_Supervised_Learning` | `logistic_regression_titanic.ipynb` | Titanic survival classification |
| `02_Supervised_Learning` | `decision_tree_iris.ipynb` | Iris species classification + overfitting demo |
| `03_Unsupervised_Learning` | `kmeans_clustering.ipynb` | Customer segmentation with K-Means |
| `04_Model_Evaluation` | `metrics_comparison.ipynb` | Accuracy, Precision, Recall, F1, ROC-AUC, Cross-Validation |
| `05_Mini_Projects` | `credit_score_predictor.ipynb` | End-to-end credit risk ML project |
