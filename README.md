# 🤖 ML Notebooks

Machine learning experiments built during B.Tech CSE (AIML) at PCCOE Pune.  
Covers EDA, supervised learning, unsupervised learning, model evaluation, and a FinTech mini-project.

## 📁 Notebooks

| Topic | Notebook | Algorithm |
|-------|----------|-----------|
| EDA | Titanic EDA | Pandas, Seaborn |
| EDA | Iris EDA | Pandas, Seaborn |
| Supervised | House Price Prediction | Linear Regression |
| Supervised | Titanic Survival | Logistic Regression |
| Supervised | Iris Classification | Decision Tree |
| Unsupervised | Customer Segmentation | K-Means Clustering |
| Evaluation | Metrics Deep Dive | Accuracy, F1, ROC-AUC |
| Mini Project | Credit Score Predictor | Random Forest, Gradient Boosting |

## 🎯 Topics Covered
- Exploratory Data Analysis (EDA) — missing values, distributions, correlation heatmaps
- Supervised Learning — regression and classification with real datasets
- Unsupervised Learning — K-Means with Elbow method and Silhouette score
- Model Evaluation — confusion matrix, ROC-AUC, cross-validation
- Mini Project — end-to-end Credit Score Predictor (extends my [CreditHealth](https://github.com/111-Vaishali/HM058_HackMatrix) hackathon project)
